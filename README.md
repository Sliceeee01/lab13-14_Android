# Unscramble Game

Игра "Разгадай слово" для Android. Нужно угадать исходное слово из перемешанных букв.

## Технологии

- Kotlin
- Jetpack Compose
- ViewModel
- StateFlow

## Функциональность

- Отображение перемешанного слова
- Поле ввода ответа
- Проверка правильности (+20 очков)
- Кнопка пропуска (без штрафа)
- Счётчик слов (1 из 10)
- Диалог завершения с итоговым счётом
- Сохранение состояния при повороте экрана

## Контрольные вопросы

**1. Что такое ViewModel и зачем он нужен?**

ViewModel хранит данные UI отдельно от Composable-функций. Без ViewModel при повороте экрана все данные (счёт, слово) теряются, т.к. Activity пересоздаётся. ViewModel сохраняет данные при повороте.

**2. В чём разница между MutableStateFlow и StateFlow?**

- MutableStateFlow — изменяемый (можно менять значение)
- StateFlow — только для чтения

`_uiState` (приватный) — для изменений внутри ViewModel.  
`uiState` (публичный) — для чтения из UI. Это **backing property pattern** — защита от случайных изменений снаружи.

**3. Почему в ViewModel нельзя хранить Context или View?**

ViewModel живёт дольше Activity. Если сохранить ссылку на Activity, то Activity не сможет удалиться из памяти → **утечка памяти**.

**4. Чем StateFlow отличается от remember и rememberSaveable?**

| Подход | Когда использовать |
|--------|-------------------|
| `remember` | Простые локальные состояния (анимация, видимость) |
| `rememberSaveable` | Небольшие данные, которые нужно сохранить при повороте |
| `StateFlow + ViewModel` | Сложная логика, общее состояние экрана, бизнес-логика |

**5. Что такое data class в Kotlin и зачем он используется для UI State?**

Data class автоматически генерирует `equals()`, `hashCode()`, `toString()`, `copy()`.  
Функция `copy()` нужна для создания копии объекта с изменением отдельных полей (удобно для обновления UI State).

**6. Как работает collectAsState() в Compose?**

`collectAsState()` подписывается на StateFlow и при каждом изменении значения вызывает перекомпозицию (перерисовку) UI.

**7. Зачем разделять код на пакеты data и ui?**

- `data` — модели данных, слова, константы
- `ui` — ViewModel и экраны

Это поддерживает **разделение ответственности (Separation of Concerns)**.

**8. Что происходит с ViewModel при закрытии приложения?**

ViewModel уничтожается, данные теряются. Для долговременного хранения нужны **Room** (база данных), **DataStore** (настройки) или файлы.
